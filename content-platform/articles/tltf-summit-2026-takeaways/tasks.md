# Tasks: tltf-summit-2026-takeaways

> The workflow gates for a LinkedIn post. Each step has an explicit
> done-when. Generated by the `content-pipeline` skill.

## 1. Outline (gate: human sign-off)

- [x] Plan.md filled in: hook (lines 1 to 2 explicitly), body beats, close
- [x] Format chosen: text-only | carousel | article-syndication
- [x] Hashtags drafted (≤3)
- [x] **Reviewer signed off on the hook + structure before draft starts**

> The hook carries more weight than any other element, because
> LinkedIn truncates around line 3 on mobile. Lock it before drafting.

## 2. Draft (gate: complete post at length target)

- [x] Hook drafted (lines 1 to 2, no setup)
- [x] Body drafted (short paragraphs, 1 to 3 sentences each)
- [x] Close drafted (CTA, question, or syndication link)
- [x] Length within target (text-only: 150 to 400 words)
- [x] No `**TBD — confirm**` markers
- [x] Draft written to `draft.md` in this article's workspace

## 3. Revise (gate: reviewer accepts)

- [x] Reviewer feedback captured
- [x] Revisions applied in `draft.md` (one source of truth)
- [x] Revision rounds repeat as needed; mark complete only when the
      reviewer accepts

## 4. Polish (gate: pre-publish checklist clean)

- [x] Hook reads cleanly cold (no "as I was saying" or context
      that requires the writer to be known)
- [x] Hashtags are 3 max, at the bottom
- [x] Personal byline if appropriate (LinkedIn rewards individual
      voice over org voice)
- [x] **Final-pass sweep against `voice/examples/avoid-this.md`**
- [x] **Final-pass sweep against `voice/style-guide.md` §5**
- [x] **Final-pass sweep against `voice/examples/ai-tells.md`** (no em
      dashes, no dash substitutes, no AI-sounding constructions)
- [x] `npm run voice:lint -- <path to draft.md>` reports 0 errors, and
      every warning has been read and either fixed or accepted

## 5. Image (gate: optional; skip if text-only)

LinkedIn posts often ship without an image. Include this step only
if the brief specifies a graphic, carousel, or syndication header.

- [ ] Carousel slides drafted (5 to 10 slides, key idea per slide), or
- [ ] Article-syndication header at `public/articles/<slug>/linkedin-1920x1080.png`
- [ ] Alt text written

## 6. Ship (gate: live + tracked)

- [ ] `draft.md` moved to `content-platform/published/linkedin-posts/<slug>.md`
- [ ] Posted to LinkedIn (manual; capture the LinkedIn URL in
      `published/linkedin-posts/<slug>.md` frontmatter as `posted_url`)
- [ ] `calendar.md` row updated to `published`
- [ ] GitHub Project's *Pipeline status* moved to `Published`
- [ ] GitHub Issue closed
- [ ] Campaign file updated to reflect actual posting
